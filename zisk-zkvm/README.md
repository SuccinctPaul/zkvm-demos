# ZisK zkVM Fibonacci Demo

This is a demonstration of using [ZisK zkVM](https://github.com/0xPolygonHermez/zisk) to compute Fibonacci numbers with zero-knowledge proofs.

## About ZisK zkVM

ZisK is an ultra-high-performance zero-knowledge virtual machine developed by Polygon (0xPolygonHermez). It provides:

- **Blazing Fast Performance**: 1.5 GHz RISC-V trace generation (~10x faster than other zkVMs)
- **RISC-V Instruction Set**: Full compatibility with RISC-V architecture
- **Rust Development**: Write guest programs in Rust
- **Efficient Memory Handling**: Decoupled memory parallelization for optimal performance
- **Low Latency**: Designed for real-time, on-demand ZK proof generation
- **Production Ready**: Developed by the Polygon team with battle-tested technology

### Key Innovation

ZisK achieves breakthrough performance through:
- Efficient code translation between RISC-V and the proving system
- Memory access parallelization and optimization
- Advanced trace generation techniques
- Optimized constraint system design

## Configuration

Set the Fibonacci number to compute via environment variable:

```bash
# Set environment variable (used during build)
export FIBONACCI_N=10

# Build to generate input.bin with this value
cd zisk-zkvm/zisk-guest
cargo build --release
```

The build script (`build.rs`) will create `build/input.bin` with the configured value.

## Building

Build the guest program to generate a RISC-V ELF file:

```bash
cd zisk-zkvm/zisk-guest

# Build with cargo-zisk
cargo-zisk build --release
```

This creates the ELF file at:
```
target/riscv64ima-zisk-zkvm-elf/release/zisk-guest
```

## Running

### 1. Test with Emulator

First, test the program using the ZisK emulator to ensure correctness:

```bash
cd zisk-zkvm

# Run with ziskemu
ziskemu -e zisk-guest/target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
        -i build/input.bin
```

Or use cargo-zisk:

```bash
cd zisk-guest
cargo-zisk run --release -i ../build/input.bin
```

Expected output:
```
Computing Fibonacci for n = 10
Fibonacci(10) = 89
```

### 2. Generate ROM Setup

Before generating proofs, you need to generate the ROM setup files (only once per program):

```bash
cd zisk-zkvm/zisk-guest

cargo-zisk rom-setup -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest
```

This may take a few minutes and creates setup files in your ZisK directory.

### 3. Generate and Verify Proof

Generate a zero-knowledge proof:

```bash
cd zisk-zkvm/zisk-guest

# Generate proof (Linux only - macOS not yet supported)
cargo-zisk prove \
  -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
  -i ../build/input.bin \
  -o ../proof \
  -a -y
```

Options:
- `-e`: ELF file path
- `-i`: Input file path
- `-o`: Output directory for proof
- `-a`: Auto mode
- `-y`: Skip confirmations

This will:
1. Execute the program in the zkVM
2. Generate execution trace
3. Create zero-knowledge proof
4. Save proof to `proof/` directory

### 4. Verify Proof

Verify the generated proof:

```bash
cd zisk-zkvm/zisk-guest

cargo-zisk verify -p ../proof/vadcop_final_proof.bin
```

Expected output:
```
[INFO ] ProofMan:     ✓ Vadcop Final proof was verified
```

## Development

### Modify the Guest Program

Edit `zisk-guest/src/main.rs` to change the computation:

```rust
use ziskos::*;

ziskos::entrypoint!(main);

pub fn main() {
    // Read input from input.bin
    let input = read_input();
    let n = u32::from_le_bytes([input[0], input[1], input[2], input[3]]);
    
    // Your computation here
    let result = your_computation(n);
    
    // Set public output
    set_output(0, result);
}
```

### Modify Input

Change the input by setting `FIBONACCI_N` and rebuilding:

```bash
export FIBONACCI_N=20
cd zisk-guest
cargo build --release  # Regenerates input.bin
```

### Debug Logging

Enable logging in the guest program:

```rust
println!("Debug: value = {}", value);
```

Run with verbose output:

```bash
cargo-zisk run --release -i ../build/input.bin
```

## Troubleshooting

### Installation Issues

**Problem**: `cargo-zisk` not found after installation

```bash
# Solution: Add to PATH
export PATH="$HOME/.zisk/bin:$PATH"

# Make permanent
echo 'export PATH="$HOME/.zisk/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

**Problem**: ZisK toolchain not found

```bash
# Solution: Reinstall toolchain
curl https://raw.githubusercontent.com/0xPolygonHermez/zisk/main/ziskup/install.sh | bash

# Or update
ziskup

# Verify
rustup toolchain list | grep zisk
```

### Build Errors

**Problem**: Build fails with linking errors

```bash
# Solution: Clean and rebuild
cd zisk-guest
cargo clean
cargo-zisk build --release
```

**Problem**: `lib-c` build errors

```bash
# Solution: This is usually handled by the installer
# If it persists, report as an issue
```

### Runtime Errors

**Problem**: `input.bin` not found

```bash
# Solution: Ensure build directory exists and contains input.bin
cd zisk-guest
cargo build --release  # Generates input.bin
```

**Problem**: Out of memory during proving

```bash
# Solution 1: Use smaller input
export FIBONACCI_N=10

# Solution 2: Increase system memory limits
ulimit -m unlimited
ulimit -v unlimited
```

**Problem**: Proof generation fails on macOS

```bash
# This is expected - macOS proof generation is not yet supported
# Use Linux for proof generation, or wait for macOS support
```

### Performance Issues

**Problem**: Proving is slower than expected

```bash
# Check that you're using release mode
cargo-zisk prove --release ...  # Not --debug

# Use all CPU cores
export RAYON_NUM_THREADS=$(nproc)

# Consider GPU acceleration (Linux only)
cargo-zisk-gpu prove ...
```
