- ❌ cargo-zisk prove (仅限 Linux)
- ❌ cargo-zisk verify (仅限 Linux)

### Linux 系统: 完整支持

在 Linux x86_64 系统上，可以执行完整的 proof 生成和验证流程：

```bash
# 1. 构建程序
cargo-zisk build --release

# 2. 生成 ROM setup（每个程序只需一次）
cargo-zisk rom-setup -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest

# 3. 生成 proof
cargo-zisk prove -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
                 -i ../build/input.bin -o ../proof -a -y

# 4. 验证 proof
cargo-zisk verify -p ../proof/vadcop_final_proof.bin
```

**预期输出**:
```
[INFO ] ProofMan:     ✓ Vadcop Final proof was verified
```

## ZisK 架构特点

与其他 zkVM（如 SP1、Risc0）不同，ZisK 使用**纯 CLI 工作流**：

| 特性 | ZisK | SP1/Risc0 |
|-----|------|-----------|
| Host 程序 | ❌ 不需要 | ✅ 需要 |
| CLI 工具 | ✅ cargo-zisk | ✅ cargo-prove |
| 工作流程 | CLI 驱动 | SDK 驱动 |
| API 风格 | 低级别（手动解析） | 高级别（泛型） |

这使得 ZisK 的项目结构更简单，但需要手动处理输入/输出的序列化。
