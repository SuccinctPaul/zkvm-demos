## 🔧 Technical Details

### Guest Program (`zisk-guest/src/main.rs`)

```rust
#![cfg_attr(all(target_os = "zkvm", target_vendor = "zisk"), no_main)]

use ziskos::*;

ziskos::entrypoint!(fibonacci_main);

pub fn fibonacci_main() {
    let input = read_input();
    let n = u32::from_le_bytes([input[0], input[1], input[2], input[3]]);
    let result = fib::fibonacci(n);
    set_output(0, result);
}
```

**Features:**
- Conditional compilation for zkVM target
- Read input from input.bin file
- Compute Fibonacci using shared library
- Set result as public output

### Build Script (`zisk-guest/build.rs`)

**Workflow:**
1. Read FIBONACCI_N from environment (default: 10)
2. Create build/ directory
3. Generate input.bin with the value
4. Trigger rebuild when environment changes

### Proof Generation (Using cargo-zisk CLI)

**Workflow:**
1. Build guest program: `cargo-zisk build --release`
2. Test with emulator: `ziskemu -e <elf> -i <input.bin>`
3. Generate ROM setup: `cargo-zisk rom-setup -e <elf>`
4. Generate proof: `cargo-zisk prove -e <elf> -i <input> -o <output>`
5. Verify proof: `cargo-zisk verify -p <proof>`

## 🎓 Usage Examples

### Basic Usage

```bash
# Install ZisK toolchain
./scripts/sdk_installers/install_zisk_sdk.sh

# Navigate to project
cd zisk-zkvm/zisk-guest

# Build guest program
cargo-zisk build --release

# Test with emulator
cargo-zisk run --release -i ../build/input.bin
```

### Custom Input

```bash
# Set custom Fibonacci number
export FIBONACCI_N=20

# Rebuild to generate new input.bin
cd zisk-guest
cargo build --release

# Run with new input
cargo-zisk run --release -i ../build/input.bin
```

### Generate Proof (Linux only)

```bash
# Generate ROM setup (one time)
cargo-zisk rom-setup -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest

# Generate proof
cargo-zisk prove -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
                 -i ../build/input.bin -o ../proof -a -y

# Verify proof
cargo-zisk verify -p ../proof/vadcop_final_proof.bin
```
