# ZisK zkVM Fibonacci Demo

> ⚠️ **Note**: ZisK currently **does not support proof generation on macOS**, only Linux x86_64 is supported.
> 
> 🐳 **macOS Users**: Please use Docker to generate proofs (see below)

---

## 🚀 Quick Start

### macOS Users (Recommended to use Docker)

```bash
# 1. Build Docker environment (first time, ~15-20 mins)
cd docker/scripts && ./build-base.sh && cd ..
docker compose build zisk-zkvm

# 2. Test run
docker compose --profile zisk up zisk-zkvm

# 3. Generate proof
ZKVM_MODE=prove docker compose --profile zisk up zisk-zkvm
```

- Quick Start: [`DOCKER_QUICKSTART.md`](DOCKER_QUICKSTART.md)

### Linux Users (Native Support)

#### 1. Install Dependencies

**Ubuntu 22.04+:**
```bash
sudo apt-get install -y xz-utils jq curl build-essential qemu-system libomp-dev \
  libgmp-dev nlohmann-json3-dev protobuf-compiler uuid-dev libgrpc++-dev \
  libsecp256k1-dev libsodium-dev libpqxx-dev nasm libopenmpi-dev openmpi-bin
```

#### 2. Install ZisK Toolchain

```bash
# Install using ziskup
curl https://raw.githubusercontent.com/0xPolygonHermez/zisk/main/ziskup/install.sh | bash

# Or use the provided script
cd /path/to/zkvm-demos
./scripts/sdk_installers/install_zisk_sdk.sh
```

#### 3. Verify Installation

```bash
cargo-zisk --version
ziskemu --version
rustup toolchain list | grep zisk
```

## 📋 Usage

### Build

```bash
cd zkvms/zisk-zkvm/zisk-guest
cargo-zisk build --release
```

### Execution (Simulator)

```bash
# Use default input (Fibonacci(10))
cargo-zisk run --release -i ../build/input.bin

# Custom input
export FIBONACCI_N=20
cargo build --release  # Regenerate input.bin
cargo-zisk run --release -i ../build/input.bin
```

### Generate Proof (Linux Only)

```bash
# 1. ROM setup (first time, ~2-5 mins)
cargo-zisk rom-setup -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest

# 2. Generate proof (~30-45 seconds)
cargo-zisk prove -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
                 -i ../build/input.bin -o ../proof -a -y

# 3. Verify proof (~2 seconds)
cargo-zisk verify -p ../proof/vadcop_final_proof.bin
```

**Expected Output:**
```
[INFO ] ProofMan:     ✓ Vadcop Final proof was verified
```

## 🐳 Docker Usage (macOS Recommended)

### Quick Commands

```bash
cd docker

# Test Mode (Build + Execute)
docker compose --profile zisk up zisk-zkvm

# Proof Mode (Full Workflow)
ZKVM_MODE=prove docker compose --profile zisk up zisk-zkvm

# Custom Input
FIBONACCI_N=20 ZKVM_MODE=prove docker compose --profile zisk up zisk-zkvm

# Interactive Shell
docker compose run --rm zisk-zkvm bash
```

### Manual Execution Inside Container

```bash
# Enter Container
docker compose run --rm zisk-zkvm bash

# Execute Commands
cd zisk-guest
cargo-zisk build --release
cargo-zisk run --release -i ../build/input.bin
cargo-zisk rom-setup -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest
cargo-zisk prove -e target/riscv64ima-zisk-zkvm-elf/release/zisk-guest \
                 -i ../build/input.bin -o ../proof -a -y
cargo-zisk verify -p ../proof/vadcop_final_proof.bin
```

## 📊 Performance Reference

### Linux x86_64 Native Performance

| Operation | Fib(10) | Fib(20) | Fib(30) |
|-----|---------|---------|---------|
| Build | ~1-2s | ~1-2s | ~1-2s |
| Execute | <0.01s | <0.01s | <0.01s |
| ROM setup | 2-5 mins (once) | Same | Same |
| Proof Gen | ~30s | ~35s | ~45s |
| Proof Verify | ~2s | ~2s | ~2s |

### macOS (Docker with emulation)

Performance is about 40-60% of native Linux:
- Execute: Normal
- ROM setup: 5-10 mins (once)
- Proof Gen: 60-90 seconds

## 🔧 Troubleshooting

### macOS: "Command is not supported"

This is normal! ZisK does not support generating proofs on macOS.

**Solution**: Use Docker
```bash
cd docker
ZKVM_MODE=prove docker compose --profile zisk up zisk-zkvm
```

### Linux: Missing Dependencies

```bash
# Install all required dependencies
sudo apt-get install -y xz-utils jq curl build-essential qemu-system \
  libomp-dev libgmp-dev nlohmann-json3-dev protobuf-compiler uuid-dev \
  libgrpc++-dev libsecp256k1-dev libsodium-dev libpqxx-dev nasm \
  libopenmpi-dev openmpi-bin
```

### cargo-zisk Not Found

```bash
# Add to PATH
export PATH="$HOME/.zisk/bin:$PATH"

# Add permanently
echo 'export PATH="$HOME/.zisk/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### input.bin Does Not Exist

```bash
# input.bin is generated by build.rs
cd zisk-guest
cargo build --release
```

## ❓ FAQ

**Q: Why is proof generation not supported on macOS?**  
A: ZisK proof generation relies on Linux-specific system features and x86_64 architectural optimizations.

**Q: How is the performance of the Docker solution?**  
A: Using Docker on macOS has about 40-60% performance, but is fully functional.

**Q: When will macOS be supported?**  
A: The ZisK team is working on macOS support, but no timeline has been announced.

**Q: Are there other zkVMs that support macOS?**  
A: Yes, SP1 and Risc0 fully support macOS proof generation.
